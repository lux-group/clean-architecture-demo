# Architecture Decision Records (ADRs)

This directory contains Architecture Decision Records that document important architectural decisions made in this project. These records help both developers and AI assistants understand the reasoning behind architectural choices.

## Format

Each ADR follows this structure:
- **Title**: Short descriptive title
- **Status**: Proposed, Accepted, Deprecated, or Superseded
- **Context**: What situation led to this decision
- **Decision**: What was decided
- **Consequences**: What are the positive and negative outcomes
